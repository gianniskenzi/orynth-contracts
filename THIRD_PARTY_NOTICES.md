# Third-party sources

The compiler inputs embed the exact dependency sources used at deployment. Original source text, SPDX identifiers, and notices are preserved.

- [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts): MIT. Copyright OpenZeppelin contributors.
- [Uniswap v4 core](https://github.com/Uniswap/v4-core): the interfaces, libraries, and types embedded here declare MIT.
- [Uniswap v4 periphery](https://github.com/Uniswap/v4-periphery), including the embedded Permit2 interfaces: embedded files declare MIT.
- [Uniswap Universal Router](https://github.com/Uniswap/universal-router): `contracts/interfaces/IUniversalRouter.sol` declares GPL-3.0-or-later. Its license text is included in `licenses/Uniswap-Universal-Router-GPL-3.0.txt`.

The repository's MIT license applies to Orynth-authored files. It does not replace the licenses of embedded dependencies. Inspect the source headers in the selected compiler input for each file's terms.
